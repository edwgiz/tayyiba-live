# Tayyiba Live

This project helps the Ummah follow a fasting schedule based on the Sunnah of the Prophet Muhammad (peace be upon him),
including obligatory, voluntary, and prohibited fasting days.

https://tayyiba.live


## Health benefits

This project encourages following the Sunnah narratives, as Muslims believe that Allah, our Creator, knows what is best
for us.


## Precautions

If you are new to healthcare and fitness or have any health conditions, it is important to be careful and start 
gradually. Consulting a doctor, dietitian, or other qualified health professional is strongly recommended before making
major changes to your daily routines, eating habits or fasting.

This project is for educational and religious purposes and should not replace professional medical advice.
