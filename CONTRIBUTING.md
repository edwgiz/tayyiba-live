# Contributing

Peace be upon you.

Thank you for your interest in contributing to the Tayyiba Live project. Any help is greatly appreciated.

This project aims to benefit the Ummah by providing accurate and helpful information about health, wellness 
and longevity according to the Sunnah of the Prophet Muhammad (peace be upon him).

## Ways to Contribute

We welcome contributions in many forms, including:

* Improving religious accuracy and references
* Reviewing Sunnah-related information
* Fixing bugs and improving code quality
* Adding new features and improvements
* Improving documentation and readability
* Translating the project into other languages
* Helping with internationalization (i18n)
* Reporting issues and suggesting ideas

## Religious Contributions

If you have knowledge in Islamic studies, Hadith, or Fiqh related to health, your feedback and corrections are
especially valuable. Please help us ensure that the information shared in this project remains respectful, authentic,
and beneficial.

## Technical Contributions

Developers, designers, and open source contributors are welcome to help improve the technical side of the project. Clean
code, accessibility, performance, and user experience improvements are always appreciated.

## Before Contributing

Please:

1. Open an issue to discuss major changes before starting work
2. Keep pull requests focused and clear
3. Write clean and understandable code
4. Be respectful and constructive in discussions

## Thank You

May Allah reward everyone who contributes to this project and helps make it beneficial for others.
